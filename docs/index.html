Translitra

Cyrillic ⇄ Latin transliteration for Chrome. Select text, see the result.

  • Tooltip with the transliteration appears when you select text on any page.
  • Direction is detected automatically.
  • Four standards: Popular, GOST 7.79-2000 (B), ICAO passport, BGN/PCGN.
  • Popup, standalone window (Alt+Shift+T) and context menu.
  • Fully offline. Nothing is sent anywhere.
